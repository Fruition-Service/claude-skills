FAQ

What is a Claude skill?
A folder with a SKILL.md file that teaches Claude how to do a specific job. Claude loads it when a task matches its description.
Where do skills go?
Personal skills: ~/.claude/skills/<name>/SKILL.md. Project skills: .claude/skills/ in your repo root.
Are these free?
Yes. The upstream library is MIT licensed.
