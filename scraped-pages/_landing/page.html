Questions

What is a Claude skill?

A skill is a folder with a SKILL.md file that teaches Claude how to do a specific job — the instructions, the steps, and any reference files it needs. Claude loads it when a task matches its description. Skills are instructions; MCP servers are connections to external tools; plugins bundle both. Most of what people want is a skill.

Where do skills go on my machine?

Personal skills live in ~/.claude/skills/<skill-name>/SKILL.md, and project-specific ones in .claude/skills/ inside the project. The folder name is the skill name. Claude Code watches those directories, so a new skill works immediately — no restart.

Do these work in Claude Cowork and the Claude app?

Most of them. Cowork and the Claude app do not read your local ~/.claude/skills/ folder — they load skills enabled on your account, uploaded as a zip. Every skill page here has a zip download and the upload steps. Skills that run shell commands or spawn agents are Claude Code only, and each one says so.

Can I use these commercially?

Yes. The library is MIT licensed. Use them at work, modify them, ship them inside your own tooling. No attribution required and no email wall.

Who maintains this?

OneWave AI. We are an AI consultancy — we train teams on Claude and build AI tools for companies from SMB to enterprise. These are the skills we actually use on client work, opened up.
